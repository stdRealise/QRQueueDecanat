# QR Queue Decanat
Система электронной очереди для деканата.

## Используемые технологии
### Frontend
- Vue.js 3
- Vite
- Axios
- SignalR Client
- Iconsax
### Backend
- ASP.NET Core 8
- Entity Framework Core
- JWT
- SignalR
### База данных
- PostgreSQL

## Настройка и запуск проекта
### Backend
Перейдите в каталог backend:
```sh
cd backend/QRQueueDecanat.Api
```
Строка подключения к PostgreSQL и секретный ключ JWT хранятся с помощью механизма .NET User Secrets и не добавляются в репозиторий. 

Укажите строку подключения к PostgreSQL: 
```sh
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Host=localhost;Port=5432;Database=QRQueueDecanat;Username=postgres;Password=YOUR_PASSWORD"
```
Укажите секретный ключ JWT: 
```sh
dotnet user-secrets set "Jwt:Key" "replace-with-a-long-random-secret-key-at-least-32-characters"
```

Параметры `Issuer`, `Audience` и время действия токена задаются в файле `appsettings.json`: 
```json 
{ 
  "Jwt": { 
    "Issuer": "QRQueueBackend", 
    "Audience": "QRQueueFrontend", 
    "AccessTokenMinutes": 480 
    } 
} 
```

Применение миграций:
```sh
dotnet ef database update
```
Запустите backend:
```sh
dotnet run
```

### Frontend
Перейдите в каталог frontend:
```sh
cd frontend
```
Установите зависимости:
```sh
npm install
```
Создайте файл .env и укажите адрес сервера. Пример:
```sh
echo "VITE_API_URL=http://localhost:5091" > .env
```
Запустите frontend:
```sh
npm run dev
```

## Привязка номера окна оператора: 
Номер окна привязывается к конкретному браузеру и сохраняется в `localStorage`.
Для настройки откройте консоль разработчика браузера и задайте номер окна. Пример:
```js
localStorage.setItem('counterNumber', '1')
```

## Структура проекта
### Студент
- `/student/services` — выбор услуги и получение талона;
- `/student/ticket` — просмотр текущего талона и его статуса.

Идентификатор текущего талона сохраняется в `localStorage`. Благодаря этому талон сохраняется после обновления страницы или закрытия вкладки.

Статус талона обновляется через SignalR.

### Информационное табло

- `/panel` — отображение вызванных талонов и общей информации об очереди.

Табло отображает до 8 последних вызванных талонов и до 5 ожидающих талонов.

### Оператор

- `/operator/start` — вход оператора и начало рабочей сессии;
- `/operator/queue` — работа с текущим талоном и очередью;
- `/operator/history` — история обслуженных и пропущенных талонов;
- `/operator/services` — выбор услуг, обслуживаемых оператором.

В `sessionStorage` сохраняются данные авторизации оператора:
- JWT-токен;
- информация об авторизованном пользователе.
В `localStorage` сохраняются:
- номер рабочего окна оператора;
- идентификатор текущего талона студента.

## Ограничения текущей версии
В текущей версии не реализованы или реализованы частично следующие функции:
- переключение оператора между состояниями «На месте» и «Перерыв» не связано с backend;
- повторный вызов уже вызванного талона отсутствует;
- студенту не показывается отдельное сообщение после отмены талона;
- не отображается подробная информация об очереди на странице студента;
- административная панель отсутствует;
- запись на конкретное время не реализована.
